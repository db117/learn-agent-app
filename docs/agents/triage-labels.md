# Triage 标签

工程技能使用以下五种标准分诊角色。本文件将这些角色映射到本仓库实际使用的标签字符串。

| Matt Pocock 技能中的标签 | 本仓库的标签      | 含义                     |
|--------------------------|-------------------|--------------------------|
| `needs-triage`           | `needs-triage`    | 维护者需要评估此任务     |
| `needs-info`             | `needs-info`      | 等待提交者补充信息       |
| `ready-for-agent`        | `ready-for-agent` | 已完整描述，可交给 Agent |
| `ready-for-human`        | `ready-for-human` | 需要人工实现             |
| `wontfix`                | `wontfix`         | 不计划处理               |

技能提到某个角色时，使用对应的本仓库标签字符串。

如果本仓库未来采用其他标签命名，可以直接编辑表格右侧列。
